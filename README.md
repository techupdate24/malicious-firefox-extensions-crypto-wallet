# Malicious Firefox Extensions Targeting Crypto Wallets

![Banner](banner.jpg)

Security researchers have identified a new wave of highly deceptive, malicious Firefox extensions specifically designed to siphon funds from browser-based cryptocurrency wallets. These extensions masquerade as legitimate security tools or productivity enhancers, bypassing initial store checks to inject keyloggers and clipboard-hijacking scripts directly into the user's browsing session.\n\nOur latest threat advisory covers the attack mechanics of these malicious add-ons, how they intercept transaction data, and the crucial browser hardening steps users must take to secure their digital assets.\n\nRead the full technical analysis on our official security portal.
